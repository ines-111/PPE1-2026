### Commandes utiles
- pwd : affiche le dossier courant
- ls : liste le contenu d'un dossier
- cd : change de dossier
- mkdir -p : crée un dossier (et ses parents)
- cp : copier
- mv : déplacer
- rm : supprimer
- cat : afficher un fichier
- head / tail : début / fin d'un fichier
- unzip : décompresser
- zip -r : compresser un dossier
- history : historique des commandes
- man : manuel d'une commande
